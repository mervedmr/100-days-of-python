# 100 Günlük Python Yolculuğu

Yazılım kariyerimin temellerini oluşturmak amacıyla Python öğrenme sürecine başlıyorum.

## Bu Challenge Hakkında

Bu süreçteki hedeflerim:

- Python'u temelden orta-ileri seviyeye kadar öğrenmek.
- Problem çözme ve algoritmik düşünme becerilerimi geliştirmek.
- Temiz, okunabilir ve sürdürülebilir kod yazmayı öğrenmek.
- Düzenli kod yazma alışkanlığı kazanmak.
